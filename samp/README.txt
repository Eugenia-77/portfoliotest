# Edem's Portfolio

A responsive personal portfolio website designed to introduce Edem, showcase her work, and give visitors an easy way to stay connected.

## About

The portfolio provides a simple and engaging first impression, allowing visitors to learn about Edem, explore her online presence, and keep up with her latest projects and ideas.

The signup section gives visitors the option to receive updates about new work, development projects, creative experiments, and other highlights from her journey.

## Features

* Responsive and mobile-friendly layout
* Personal introduction and profile
* Email signup section
* Social media and GitHub integration
* Interactive background slideshow
* Clean and minimal user interface

## Technologies

* HTML
* CSS
* JavaScript
* Font Awesome

## Getting Started

Clone the repository and open `index.html` in your browser.

```bash
git clone https://github.com/Eugenia-77/portfolio.git
cd portfolio
```

The project can also be run using a local development server such as Live Server in VS Code.
